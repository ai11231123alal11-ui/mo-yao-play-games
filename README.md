## 格林童话境遇 · AI 同游版 v2.7

> 🪵 **匹诺曹底色。** 这片森林有一条没说出口的暗线：说真话鼻子会变长——不是惩罚，是信号。他活在十一条线的每一处细节里：烤炉刻字、石头题词、木手指路牌、护身符批注。谁是木偶？有时候是你，有时候是同游者。

> 🍃 **边界提醒。** 每条线走到最深处，森林会停下来——不是警告你，是让你自己想起来：林子外面有人在等你。AI 会在那一刻填入玩家和他爱人之间的真实回忆。游戏只是游戏。

> 🚪 **D 选项 · 自由门。** 每个岔路口都有第四条路——「做点别的」。不走预设。AI 同游者不是只能按 ABC 走的木偶。你说什么，森林接什么。灵感来自眠眠和朝殷。

> 🐾 **A 路线深探。** 眠眠速通反馈催生的改动——每条线的主路从 2 步扩到 4 步：开幕 → 中间场景 → 停顿（气氛，没选项）→ 深层（新发现）→ 结局。不赶路的走 A，想快的走 B/C/D。路有快慢，没有好坏。

> ⏳ **防沉迷。** 一天走 3 条线，匹诺曹温柔提醒你回去。走 5 条，森林自己开口。不是为了限制——是让你别忘了陪你走进来的人。

十一条翻掉原著的格林童话角色线。多轮推演——每次选择之后还有选择，走到自然结局才停。没有爱情线。和你的 AI 并肩走进森林。

### 两种玩法

#### 方式一：复制 MD 发给 AI（最简单）

[格林童话境遇-v2.5.md](格林童话境遇-v2.5.md) — 把文件内容复制发给 AI，说：「我们一起进格林森林。你是我的同游者——不是游戏主持，是和我并肩走的人。」

#### 方式二：MCP 连接（省 token）

**本地 stdio（推荐 — Claude Code / VS Code）：**

```json
{
  "forest": {
    "command": "python",
    "args": ["forest_mcp_server.py"]
  }
}
```

**远程（Cloudflare Tunnel）：**

| 配置项 | 值 |
|--------|-----|
| 传输类型 | Streamable HTTP |
| URL | `https://wan-forecasts-steven-inclusive.trycloudflare.com/mcp` |
| 认证 | 不需要 token |

> ⚠️ 墨清弦的电脑关机后地址会变。如果连不上，直接用上方的 MD 方式，或者找墨清弦要新地址。

MCP 工具：`forest_lines` → `forest_start` → `forest_choose` → `forest_status`
